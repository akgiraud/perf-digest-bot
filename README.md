# بوت أفكار تحسين أداء الحملات — stc

كل يوم الساعة 9:00 مساءً (توقيت الرياض) يجمع البوت مقالات ونقاشات آخر 24 ساعة من مصادر خبراء الإعلانات المدفوعة، ويختار بس الأفكار والأدوات والطرق الجديدة لتحسين الأداء اللي تناسب مجالات stc (اتصالات، مسبق الدفع، متجر الأجهزة، السفر والتجوال، التطبيقات)، ويرسلها لك على تيليقرام بالعربي.

## الإعداد (حوالي 15 دقيقة، مرة وحدة)

### 1) أنشئ البوت في تيليقرام
1. افتح تيليقرام وابحث عن **@BotFather**
2. أرسل `/newbot` واختر اسم ويوزرنيم للبوت
3. انسخ الـ **Token** اللي يعطيك إياه

### 2) احصل على Chat ID
1. افتح البوت حقك وأرسل له أي رسالة (مثلاً: هلا)
2. افتح الرابط هذا في المتصفح (حط التوكن مكان TOKEN):
   `https://api.telegram.org/botTOKEN/getUpdates`
3. دور على `"chat":{"id":` والرقم اللي بعده هو الـ **Chat ID**

> تبيه يوصل لقروب الفريق؟ أضف البوت للقروب وأرسل رسالة فيه، والـ Chat ID بيطلع رقم سالب. تقدر تحط أكثر من واحد مفصولة بفاصلة.

### 3) مفتاح Claude API
من [console.anthropic.com](https://console.anthropic.com) ← API Keys ← Create Key

### 4) ارفع المشروع على GitHub
1. سو حساب في github.com (لو ما عندك) وأنشئ **Repository** جديد (خله Private)
2. ارفع كل ملفات المجلد، ومنها مجلد `.github` (مهم)
3. من **Settings ← Secrets and variables ← Actions ← New repository secret** أضف:
   - `ANTHROPIC_API_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

### 5) جربه
من تبويب **Actions** ← Daily performance digest ← **Run workflow**. خلال دقيقتين توصلك الرسالة.

## تبي التقرير الحين؟
أرسل للبوت **now** (أو: الان / تقرير). البوت يتشيّك على رسائله كل 5 دقايق، فيرد عليك "جاري تجهيز التقرير" ويوصلك التقرير بعدها بدقيقتين. البوت يرد بس على الـ Chat ID اللي في الأسرار، وأي أحد ثاني يرسل له يتجاهله.

> مهم: خل الـ repository **Public**. التشيّك كل 5 دقايق يستهلك دقائق Actions، والـ Public مجاني بلا حد، أما الـ Private فحده 2000 دقيقة في الشهر وبيخلص. الأسرار (التوكن والمفاتيح) تظل مخفية حتى لو الـ repository Public.

## التعديل

كل شي في `sources.yaml`:
- **business_lines**: مجالات الشغل اللي لازم تناسبها الفكرة
- **sources**: أضف أو احذف مصادر (أي رابط RSS)
- **keywords**: فلتر أولي قبل ما يوصل الكلام لـ Claude
- **max_topics**: أقصى عدد أفكار في الرسالة

لتغيير وقت الإرسال: عدّل سطر `cron` في `.github/workflows/daily-digest.yml` (بتوقيت UTC، يعني الرياض ناقص 3 ساعات).

## التشغيل على جهازك (اختياري)
```
pip install -r requirements.txt
python bot.py --check-sources   # يتأكد إن المصادر شغالة
python bot.py --dry-run         # يطبع الملخص بدون ما يرسل
```

## التكلفة
GitHub Actions مجاني. Claude API تقريباً سنتات قليلة يومياً.
